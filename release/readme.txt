based on midi2ay 0.1 (c) 2005 Quique Llaría <qllaria@yahoo.es>

py version that converts midi file to ASM listing to be compiled by PASMO

Example:

python mid2ayEx.py nokia.mid

Then in Pasmo:

.\pasmo --tapbas nokia.asm nokia.tap

This should play convert the mid using the origianl midi2ay algorithm, and allow the track to play through once, then exit cleanly to basic

FOr use with the ZX Spectrum
